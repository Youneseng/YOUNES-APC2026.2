Nas Lições 7 a 12, o percurso vai de exibir texto na tela (Lição 7 — Text) até interações mais ricas com o usuário: primeiro entendendo o draw loop, a função que roda em repetição várias vezes por segundo e é a base de toda animação (Lição 8), depois usando variáveis para mover uma sprite pela tela a cada frame desse loop (Lição 9), em seguida acrescentando lógica condicional (if/else) para o programa reagir a situações diferentes, como uma sprite mudar de direção ao tocar a borda da tela (Lição 10), e por fim capturando entrada do teclado (Lição 11) e do mouse, posição e cliques (Lição 12) para o usuário controlar diretamente o que acontece no programa.
